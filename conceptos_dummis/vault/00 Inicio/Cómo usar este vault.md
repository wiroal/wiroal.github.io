# Cómo usar este vault

## Qué es

Un cuaderno de estudio para los Doce Conceptos para el Servicio Mundial, escrito para una RSG que está fundando un grupo en el Distrito 2, Área C.3 (Bogotá D.C.). No es literatura aprobada: es una guía de práctica.

## Cómo abrirlo

1. Abre Obsidian.
2. **Abrir carpeta como vault** y elige la carpeta `vault` de este proyecto.
3. Empieza en [[MOC - Doce Conceptos]].
4. Abre el gráfico (icono de constelación) para ver cómo se conectan los Conceptos, las semanas y las tensiones.

## Cómo estudiarlo

- **Una semana a la vez.** No leas los doce de corrido.
- **Tres sesiones por semana.** A (leer y traducir), B (ubicar y mapear), C (aplicar y contar).
- **Una micro-acción por Concepto.** Si no hay acción, no hay estudio.
- **Escribe en la bitácora.** Cinco líneas bastan.
- **Cuéntaselo a alguien.** Si no puedes explicarlo sin leer, vuelve a la Forma corta.

## Los cuatro estados

| Estado | Significa |
|---|---|
| `sin-empezar` | No lo he leído. |
| `leido` | Lo leí, pero no lo puedo explicar. |
| `entendido` | Lo explico con mis palabras y un ejemplo. |
| `aplicado` | Hice la micro-acción en mi grupo o Distrito. |
| `ensenado` | Lo compartí con otra persona o en una reunión. |

Cambia el campo `estado` en el frontmatter de cada Concepto. No es una nota: es una brújula.

## Cómo usar las plantillas

- [[Plantilla - Concepto]] para una nota nueva de estudio.
- [[Plantilla - Semana]] para una semana.
- [[Plantilla - Diario de servicio]] para una entrada de bitácora.

## Privacidad y anonimato

Este vault no incluye apellidos ni el nombre del grupo. Si lo publicas o lo compartes, revisa que no hayas agregado datos personales. Por la Tradición 11, la discreción también es parte del servicio.
