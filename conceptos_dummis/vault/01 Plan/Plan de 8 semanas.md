# Plan de 8 semanas

> [!info] La idea
> Ocho semanas, tres sesiones cortas por semana y una micro-acción. Si una semana se cae, no se repone: se continúa. La constancia vale más que el calendario perfecto.

## Cómo se estudia

Cuatro preguntas para cada Concepto:

1. **¿Qué dice?** La Forma corta y el ensayo de Bill.
2. **¿Por qué existe?** Qué problema resolvía y qué problema resuelve hoy.
3. **¿Dónde lo vivo?** Un caso real de tu grupo, tu Distrito 2 o tu Área C.3.
4. **¿Qué hago distinto?** Una micro-acción esta semana.

## La sesión de 35 minutos

| Minutos | Qué haces |
|---|---|
| 0–5 | Llegada: lee la Forma corta en voz alta. Respira. Una intención. |
| 5–15 | Lectura activa: subraya solo tres frases del ensayo. |
| 15–25 | Traducción: explícalo en voz alta, sin jerga, como a alguien nuevo. |
| 25–32 | Ubicación: un caso real y qué harías distinto. |
| 32–35 | Micro-acción: una sola cosa para esta semana. |
